# Curriculum: Полная программа обучения Java + Angular для Senior-интервью

> **Цель:** Структурированная 10-недельная программа, ведущая от основ Java/Angular до уверенного прохождения Senior-интервью на французском рынке.
> **Формат:** 6 модулей, каждый с темами, практическими заданиями и вопросами для самопроверки.
> **Интеграция с книгой:** Каждый модуль ссылается на конкретные главы.

---

## Обзор программы

| Модуль | Название | Длительность | Главы книги |
|--------|----------|:------------:|:-----------:|
| 1 | **Java Core** | 2 недели | 1 |
| 2 | **Spring Boot** | 2 недели | 2 |
| 3 | **Angular** | 2 недели | 3 |
| 4 | **Миграция и Архитектура** | 1 неделя | 4–11 |
| 5 | **Микросервисы и Cloud** | 2 недели | 9–10, 17 |
| 6 | **Интервью-подготовка** | 1 неделя | 12–16, 18 |

**Всего:** 10 недель (2.5 месяца) интенсивной подготовки.

## Модуль 1: Java Core (2 недели)

> **Цель:** Уверенное владение Java 21: типы, OOP, Collections, Streams, многопоточность, Records.
> **Ссылка:** Глава 1 (Java Core)

### Неделя 1.1: Основы языка

| День | Темы | Практика |
|:----:|------|----------|
| 1 | Типы данных, примитивы vs объекты, autoboxing | Написать классы с разными типами полей |
| 2 | ООП: наследование, инкапсуляция, полиморфизм | Реализовать иерархию `Animal → Dog/Cat` |
| 3 | Overloading vs Overriding, `@Override` | Написать примеры обоих, объяснить разницу |
| 4 | Abstract class vs Interface (Java 8+) | Переписать иерархию на интерфейсы с `default` методами |
| 5 | Access modifiers, packages | Создать пакетную структуру, проверить видимость |
| 6 | Records, Sealed Classes | Переписать DTO на `record`, запечатать иерархию `Shape` |
| 7 | **Повторение + CodinGame** | Задачи: «Температуры», «ASCII Art» |

### Неделя 1.2: Продвинутые темы

| День | Темы | Практика |
|:----:|------|----------|
| 1 | Collections: List, Set, Map, Queue | Реализовать `HashMap` вручную (упрощённо) |
| 2 | `equals()` и `hashCode()` контракт | Написать корректную реализацию для `User` |
| 3 | Streams API: filter, map, flatMap, collect | Обработать список заказов: группировка, сумма, топ-N |
| 4 | Streams: parallel streams, performance | Сравнить последовательную и параллельную обработку |
| 5 | Exceptions: Checked vs Unchecked, try-with-resources | Написать свой Exception + глобальный обработчик |
| 6 | Многопоточность: Virtual Threads, ExecutorService | Запустить 10_000 Virtual Threads, сравнить с platform threads |
| 7 | **Тест: 30 вопросов по Java Core** + CodinGame | Пройти мини-тест на время |

### Вопросы для самопроверки (Модуль 1)

1. Чем отличается `==` от `.equals()` для String?
2. Как работает autoboxing и где возникают подводные камни?
3. Почему `List<int>` не компилируется, а `List<Integer>` — да?
4. Что такое `? super T` и `? extends T` в дженериках?
5. В чём разница между `synchronized` и `ReentrantLock`?
6. Как `Virtual Threads` решают проблему thread-per-request?
7. Что такое `Record` и почему его нельзя использовать как Entity Hibernate?

### Практическое задание

> **CRUD-приложение на чистом Java** (без Spring): консольное приложение для управления списком задач. Используйте Records для DTO, Streams для фильтрации, коллекции для хранения. Напишите unit-тесты JUnit 5.

## Модуль 2: Spring Boot (2 недели)

> **Цель:** Уверенное владение Spring Boot 3: IoC/DI, REST API, JPA/Hibernate, Security, AOP, Testing.
> **Ссылка:** Глава 2 (Spring Boot)

### Неделя 2.1: Core Spring

|:----:|------|----------|

| 3 | REST Controllers: `@GetMapping`, `@PostMapping`, `@RequestBody`, `@Valid` | Создать CRUD для `Product` с валидацией |
| 4 | DTO Records, ModelMapper/MapStruct | Преобразовать Entity → DTO и обратно |
| 5 | Global Exception Handler: `@RestControllerAdvice` | Написать обработчик для всех исключений |
| 6 | Spring Data JPA: `JpaRepository`, custom queries | Создать `UserRepository` с 5 кастомными методами |
| 7 | **Повторение:** собрать мини-API | Product API (CRUD + поиск) |

### Неделя 2.2: Spring Pro

| День | Темы | Практика |
|:----:|------|----------|
| 1 | JPA Relationships: `@OneToMany`, `@ManyToMany`, `mappedBy` | Создать `Order` → `OrderItem` связь |

| 4 | Spring Security: SecurityFilterChain, JWT | Настроить JWT аутентификацию |

| 7 | **Тест: 30 вопросов по Spring** | Мини-тест + Code Review чужого кода |

### Вопросы для самопроверки (Модуль 2)

1. Как Spring создаёт бины? Что такое Component Scanning?
2. В чём разница между `@Component`, `@Service`, `@Repository`?
3. Как работает `@Transactional` под капотом? Что такое Proxy?
4. Почему возникает Self-Invocation и как его исправить?
5. Как работает Security Filter Chain? Где вставляется JWT Filter?
6. Как решить проблему N+1 с помощью `JOIN FETCH`?
7. Чем `@MockBean` отличается от `@Mock`?

### Практическое задание

> **Task Tracker API** (начало Главы 16): создать Spring Boot приложение с сущностями `Task` и `Category`, REST API, JWT-безопасностью и глобальным обработчиком ошибок. Покрыть тестами сервисный слой.

## Модуль 4: Миграция и Архитектура (1 неделя)

> **Цель:** Сформировать «историю миграции» для интервью. Понять стратегии, боли и Business Value.

| 3 | **Java 8 → 21**: javax→jakarta, модульность JDK, GC, Virtual Threads | Написать скрипт OpenRewrite для миграции |

| 7 | **Повторение**: прогнать всю историю миграции вслух | Ответить на вопросы: «почему 2.5 года?», «какие были блокеры?» |

### Вопросы для самопроверки (Модуль 4)

1. С чего начать миграцию legacy-приложения?
2. Почему нельзя обновить Angular с v8 до v20 за один шаг?

### Практическое задание
